# TradeClawNewsAI

TradeClawNewsAI is an AI-powered bot that listens to a Telegram channel and automatically posts optimized crypto news updates to Binance Square.

## Features

- Listens to messages in a Telegram channel.
- Rewrites and optimizes content with AI.
- Posts content to Binance Square automatically.
- Supports logging and monitoring.
